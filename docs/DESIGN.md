# 視覺設計規格

依「2026 台灣普利司通經銷商年度大會」主視覺（`assets/reference/keyvisual-original.pdf`，共 3 頁）設計。風格：白底、紅色斜切色塊與圓點、淡藍幾何圖形，斜向排列帶速度感；內容區保持白底好讀。

## 色彩（取自主視覺）

| Token | 色碼 | 用途 |
| --- | --- | --- |
| `--red` | #E60013 | 主按鈕、重點數字（房號、桌次）、進度條 |
| `--red-dark` | #921E23 | 按下狀態、警示 |
| `--blue-light` | #DDECF4 | 區塊底色、次要卡片 |
| `--blue-gray` | #9CB6C6 | 次要文字、線框、分隔線 |
| `--ink` | #000000 | 主要文字 |
| `--paper` | #FFFFFF | 底色、卡片 |

狀態色：已完成 / 已兌換用 `--blue-gray` 底加勾選圖示，避免和主紅色混淆；錯誤訊息用 `--red-dark`。

## 字型

- 標題：HONOR Sans TC Medium（設計稿用字）。尚未確認網頁授權，先用 **Noto Sans TC 700**。
- 內文：Noto Sans TC 400；英文副標用 Noto Sans TC 300，字距加寬（如主視覺的 `2026 BRIDGESTONE DEALER CONVENTION`）。
- 用 Google Fonts 載入並 `display=swap`，只取需要的字重。

## 版型

- **首頁（輸入姓名）**：上方主視覺圖（手機用 `hero-mobile.jpg`，≥ 768px 用 `hero-wide.jpg`），下方白色卡片放姓名輸入框與紅色「查詢」按鈕。
- **內頁（確認身分、住宿規範、完成頁）**：仿第 2 頁，背景為淡化的圖案（`strip-top.jpg` 疊白色 70–80% 遮罩，或 CSS 漸層淡出），內容放白色圓角卡片（圓角 16px，淡陰影），右上角放 logo。
- **完成頁**：房號與桌次用大字紅色數字並排成兩張卡；QR Code 區塊白底大留白；問卷與贈品依狀態顯示。
- **後台**：白底、上方細的 `strip-top.jpg` 條，數據卡用 `--blue-light` 底、紅色大數字；表格在手機上改為卡片列表。
- 圓角：卡片 16px、按鈕 12px、輸入框 12px。按鈕高度至少 48px。
- 斜切元素：可用 CSS `clip-path` 做少量斜切色塊點綴（如卡片標題前的紅色斜條），呼應主視覺，但不要蓋到內容。
